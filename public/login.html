Object Classification and Robotic Sorting System using Tiny-Machine Learning

A comprehensive edge-AI solution integrating ESP32-CAM vision modules, MobileNetV2 transfer learning via Edge Impulse, and automated robotic sorting.

Researched by: Mg Aung Ko Phyoe
Supervised by: Daw Tin Nyo Maw

Abstract

Project Summary
01

This thesis presents an object classification and robotic sorting system that utilizes Tiny-Machine Learning with an ESP32-CAM and a central ESP32 connected via a serial UART interface.

02

A custom MobileNetV2 model was trained in Edge Impulse Studio using a 96x96 pixel resolution, grayscale input channels, and a 16-neuron dense layer, achieving 97.6% accuracy.

03

Classification classes, confidence scores, and captured images are packaged into JSON payloads and transmitted via HTTP POST requests to a Node.js and Express.js backend hosted on Vercel.

04

The backend securely manages data storage by uploading image files to Cloudinary and recording operational data within a MongoDB database.

05

A web dashboard built with HTML and Tailwind CSS is powered by the system to facilitate comprehensive real-time monitoring and historical analytics.

System Technology Architecture

Edge Impulse & MobileNetV2

Transfer learning using pre-trained MobileNetV2 optimized on Edge Impulse for efficient micro-controller image inference.

ESP32-CAM & ESP32

ESP32-CAM acts as the vision capture node (OV2640 sensor), communicating with the main ESP32 controller managing real-time tasks.

Conveyor & Servo Arms

A DC motor drives the conveyor belt through motor drivers, while precise servo motors control the robotic sorting gates.

Node.js & Express Backend

RESTful API server built using Node.js and Express to receive classification events from the hardware edge node.

MongoDB Cloud Database

Secure cloud storage utilizing MongoDB to retain history logs, confidence metrics, and misclassification records.

Vercel Cloud Hosting

The admin dashboard and cloud backend are hosted on Vercel for fast, global availability and live data streaming.

System Workflow

Step 01

Conveyor Feed

DC motor precisely moves the product under the ESP32-CAM active optical field.

Step 02

TinyML Inference

Optimized MobileNetV2 model classifies the item locally at the edge.

Step 03

Robotic Sorting

High-torque servo arm dynamically directs the item into its designated bin.

Step 04

Cloud Logging

MongoDB seamlessly stores real-time telemetry via Node.js API hosted on Vercel.
